# Iṣẹ́ Studio documentation

**Iṣẹ́ Studio** (*iṣẹ́*, Yoruba for "work") is an agent-native engineering app: mechanical parts and assemblies, printed circuit boards, buildings, sheet metal, drawings, simulation, photoreal renders and 3D for the web, in one project, where an AI builds and verifies whole products and every change is one undoable revision.
